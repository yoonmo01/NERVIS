# Brain Anatomy Rebuild Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. 현재 요청은 계획 작성이며 구현은 시작하지 않는다.

**Goal:** 기존 홀로그램 표현과 좌우 독립 20개 신호 연결을 유지하면서 참고 이미지의 뇌 윤곽·큰 주름·안쪽 피질 형태를 갖춘 일반 모형으로 교체한다.

**Architecture:** 해부학적 기본 뇌와 선택 가능한 ROI를 같은 좌표계에서 구성한다. 10종의 임의 덩어리를 합쳐 외피를 만들지 않는다. ROI는 좌우 20개 독립 식별자를 유지하고, 소뇌·뇌간은 신호 없는 형태 보조 구조로 추가한다.

**Tech Stack:** Blender, GLB, 기존 React/Three.js 렌더러와 셰이더.

**Spec:** 사용자의 2026-10-23 형태 수정 계획 요청과 첨부 이미지1–4; `reports/brain-model/reference-audit-20261023-01/REVIEW.md`; 기존 연동 계약은 `docs/BLENDER_HANDOFF.md`, `docs/FRONTEND_DESIGN.md`.

## Global Constraints

- 색상·입자·투명감·좌우 분리·기존 선택 UI를 유지한다.
- 10종 × 좌우 = 20개 ROI. 각 ROI 전체가 한 시점의 동일한 신호 강도를 따르며 좌우는 독립이다.
- 일반 뇌와 제공 데이터의 의미적 연결이다. 개인별 정확한 경계를 복원했다고 표시하지 않는다.
- 원본 폴더 쓰기, 외부 데이터 업로드, 실계정 API 호출, 환경 파일 변경, 커밋·푸시를 하지 않는다.
- 기존 미커밋 변경을 보존한다. 새 결과는 기존 보고서를 덮어쓰지 않는 별도 디렉터리에 둔다.
- 비율 변경이나 카메라 변경만으로 형태 목표를 달성했다고 판정하지 않는다.

## Review Focus

1. 측면에서 다시 타원형 덩어리로 보이는지: 단색 측면 형태 검수에서 먼저 판정한다.
2. 발광이 고랑을 지우는지: 실제 웹 표시 크기에서 단색/홀로그램을 같은 시점으로 대조한다.
3. 안쪽 ROI가 외피에 묻히거나 임의 구체로 보이는지: 안쪽 세 종류를 각각 선택해 확인한다.
4. 좌우 ID 반전 또는 같은 신호 복제: 10쌍에 서로 다른 강도를 넣어 검증한다.
5. 신호 없는 보조 구조가 선택·발광하는지: 20개 선택 전환 전체에서 소뇌·뇌간의 비반응을 검증한다.

## 변경 범위

- 새 Blender 작업본과 검수 이미지: `reports/brain-model/anatomy-rebuild-20261023-01/` (기존 경로가 있으면 새 번호).
- 모델·매핑·표현 계약: `frontend/src/assets/nervis-hologram-brain.glb`, `hologram-region-map.json`, `hologram-render-contract.json`.
- 로더 검증: `frontend/src/SchematicBrain.tsx`. 현재 22개 메시 전제에 보조 구조 2개를 명시적으로 반영한다.
- 회귀 검사: `frontend/src/hologramModel.test.ts`. 카메라/BrainStage는 새 모델의 프레이밍에 필요한 경우에만 변경한다.
- 셰이더는 기존 표현을 재사용한다. 큰 형태를 가리는 발광이 확인될 때만 기존 파라미터를 최소 조절한다.
- 완료 기록: `docs/BLENDER_HANDOFF.md`, `docs/FRONTEND_DESIGN.md`와 새 결과 디렉터리의 검수 기록. 백엔드·AI·데이터 분석은 변경 범위가 아니다.

## Task 1: 기본 형태 선정과 단색 검수

**입력:** 참고 이미지, 현재 모델 및 라이선스 기록. **출력:** 검수된 일반 뇌 기본 메시와 출처 기록.

- [ ] 기존 자산/장면을 별도 백업하고 Git 변경 목록을 기록한다.
- [ ] 큰 고랑·측두부·안쪽 피질이 있는 해부학 기반 메시를 조사한다. 출처, 사용·수정·배포 조건, 실제 포함 구조를 확인한 후보만 사용한다. 아직 새 후보를 선정한 상태는 아니다.
- [ ] 대뇌 좌우와 소뇌·뇌간의 비율/좌표계를 맞춘다. 부적합한 기존 외피를 단순 확대·축소해 재사용하는 접근은 중단한다.
- [ ] 발광·입자를 끈 단색 정면/측면/상면/안쪽 캡처를 만든다. 측면은 참고 이미지2·3과 방향을 맞춰 대조하고, 이미지1은 안쪽 구조 참고로만 사용한다.
- [ ] 측두부의 아래쪽 돌출·패임, 앞뒤 윤곽, 굵은 이랑과 깊은 고랑, 소뇌·뇌간이 식별되는지 기록한다. 미달이면 다음 단계로 진행하지 않고 기본 메시를 다시 수정한다.

## Task 2: 기본 뇌에 좌우 20개 선택 영역 구성

**입력:** Task 1의 기본 메시. **출력:** 기존 ID/이름을 유지하는 ROI 20개와 공통 좌표계의 보조 구조.

| 좌/우 ID | 범주 |
|---|---|
| 1 / 11 | 전전두피질 |
| 2 / 12 | 운동/운동전피질 |
| 3 / 13 | 체성감각피질 |
| 4 / 14 | 후두정피질 |
| 5 / 15 | 상측두피질 |
| 6 / 16 | 중/하측두피질 |
| 7 / 17 | 내측측두피질 |
| 8 / 18 | 후두/시각피질 |
| 9 / 19 | 대상피질 |
| 10 / 20 | 섬엽피질 |

- [ ] 기본 메시의 영역 라벨/출처 정의와 위 범주 사이의 대응표를 작성한다. 제공 데이터 범주보다 세밀한 개인별 경계를 주장하지 않는다.
- [ ] 바깥쪽 ROI는 기본 뇌의 주름을 공유하는 표면 패치로 구성한다. 한 ROI에 여러 부분이 필요하면 하나의 선택 그룹 안에 유지한다.
- [ ] 내측측두·대상·섬엽은 적절한 안쪽 피질 표면을 구성한다. 현재의 임의 타원체·튜브를 디테일 완성본으로 재사용하지 않는다.
- [ ] 외피 2개 + ROI 20개 + `Cerebellum_Context`, `Brainstem_Context` 2개의 계약으로 내보낸다. 보조 구조에는 ROI ID를 부여하지 않는다.
- [ ] 20개를 하나씩 단색 강조해 위치·좌우·외피와의 정합을 확인하고 대응표와 함께 저장한다.

## Task 3: 기존 홀로그램과 신호 연결

**입력:** Task 2의 메시와 기존 시계열/선택 계약. **출력:** 새 형태를 표시하는 기존 웹 무대.

- [ ] 기존 색·투명도·입자 재질을 새 표면에 적용하고 입자 위치를 새 메시에서 생성한다. 중앙 분리 간격과 좌우 그룹 관계를 유지한다.
- [ ] GLB 검사에 예상 24개 메시, 정확한 보조 구조 이름, 20개의 유일한 ROI ID, 필요한 속성 범위, 외부 이미지/버퍼 없음의 조건을 추가하고 기존 모델에서 차이를 확인한다.
- [ ] `SchematicBrain.tsx`의 메시 검증을 이 명시적 계약으로 변경한다. 알 수 없는 메시를 무조건 허용하지 않는다.
- [ ] 기존 `signalStrength`와 선택 연결을 그대로 사용한다. ROI 표면·입자는 같은 강도를 공유하고, 별도의 임의 시간 신호는 만들지 않는다. 소뇌·뇌간은 기본 표현만 가진다.
- [ ] 안쪽 영역을 선택하면 외피의 투명감을 통해 위치가 읽히도록 확인한다. 필요한 경우 기존 사선 보기로 전환하며, 모델 자체의 부정확한 형태를 카메라로 감추지 않는다.

## Task 4: 동작·형태 최종 검수

**출력:** 실제 앱 캡처와 검증 결과. 미달 항목이 있으면 완료로 표시하지 않는다.

- [ ] `frontend/`에서 `npm.cmd test`, `npm.cmd run build`를 실행하고 결과를 새 보고서에 저장한다.
- [ ] 20개 각각을 선택하고 강도 0/0.5/1에서 같은 ROI의 표면·입자가 함께 반응하는지 확인한다. 강도 0에서도 선택 식별은 남아야 한다.
- [ ] 10개 좌우쌍을 (0,1), (1,0), (0.25,0.75)로 검사해 반전/복제를 배제하고 소뇌·뇌간은 반응하지 않는지 확인한다.
- [ ] 실제 재생의 처음/끝 샘플, 선택 변경, 수동 시점 유지 동작을 확인한다. 신호 매핑의 기존 정규화 의미를 바꾸지 않는다.
- [ ] 실제 웹 정면/측면/사선 캡처를 남긴다. 단색 검수와 같은 각도로 참고 이미지와 비교하고 실제 표시 크기에서 큰 주름과 내부 ROI가 읽히는지 판정한다.
- [ ] 원본 보존은 기존 manifest와 읽기 전용 해시 대조로 확인하고 기준 파일은 갱신하지 않는다. 결과에 이번 실행과 이전 기록을 구분한다.
- [ ] 정면 사진을 사용자에게 제공하고 형태·20개 선택·좌우 신호·보존 항목 각각의 통과/미달/미검증을 보고한다.

## 계획 자체 점검

색/입자/투명/분리 보존은 Task 3, 전체 형태는 Task 1, 20개 범주와 내부 표현은 Task 2, 독립 시계열과 최종 사진은 Task 4가 담당한다. 새 모델의 라이선스·품질은 아직 검증하지 않았다. 이 계획 작성으로 모델 수정이나 해부학적 정확성 검증이 완료된 것은 아니다.
