## 촬영 전

- ElevenLabs 설정을 적용한 백엔드를 실행하고 브라우저를 새로고침한다.
- 화면과 사용자 마이크, 앱 출력 음성이 모두 녹음되는지 짧게 확인한다.
- 헤드셋을 사용해 앱 음성이 다시 질문으로 들어가지 않도록 한다.
- 사용자 설정/키/로그 창은 녹화하지 않는다. 알림도 정리한다.
- 실제 분석을 사용할 것이므로 모든 질문의 결과를 눈으로 확인한다.
- 마이크 질문 후 약 1.5초 쉬고, 확정된 입력을 확인해 보내기를 누른다.
  요청/음성이 끝난 뒤 다음 질문을 한다. 자동 전송은 없다.

켜진 상태에서 한다. 대기가 꺼져 있으면 헤더의 ‘음성 호출 켜기’를 사용한다.
호출어를 놓치면 기존 마이크 버튼을 사용할 수 있다. 실패를 성공 테이크처럼 붙이지 않는다.

응답이 너무 길면 다음 테이크에서 같은 질문에 “핵심 한 문장으로 설명해줘”를 덧붙인다.
서버 동작 자체가 이 길이를 보장하는 것은 아니다. 새 요청마다 유료 AI/TTS 사용량이
발생할 수 있으므로 반복 촬영은 사용자가 정한 예산 안에서 진행한다.

## 화면 보충 촬영

분석 결과가 나온 뒤 왼쪽 탭을 직접 선택해 MRI·응답·계산 결과를 각각 잠깐 보여준다.
MRI는 이미지와 영역명, 계산 결과는 실제 지표·단위, 오른쪽 패널은 상관계수와 분석
범위를 읽을 시간을 준다. 새로운 기능을 호출하는 대사로 연출하지 않는다.
전체 질문을 더 넣기보다 이 보충 화면을 짧게 사용하는 편이 좋다.

최소 한 질문은 사용자 발화→입력 확인/전송→실제 결과→음성 설명까지 무편집 테이크로
확보한다. 긴 대기는 편집에서 줄일 수 있지만 다른 질문의 결과와 바꾸어 붙이지 않는다.
영역의 관계선을 실제 신경 섬유로, 밝기와 재생 속도를 실제 뇌 촬영 속도로 설명하지 않는다.
