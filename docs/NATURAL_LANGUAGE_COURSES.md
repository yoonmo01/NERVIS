# 자연어 수업 등록

등록만 지원한다. 기존 courses/class_meetings에 저장하며 새 테이블·마이그레이션은 없다. 수업 수정/삭제·휴강·보강·반복 할 일은 이번 범위가 아니다.

입력 예시 (실제로 입력하면 개인 DB에 저장됨):

> 인공지능 수업 등록해줘. 2026년 2학기이고 학기 기간은 2026-09-01부터 2026-12-20까지야. 매주 월요일 오전 9시부터 10시15분까지 공학관301, 수요일 오후1시부터2시15분까지 공학관302에서 해.

실제 과목명·학기명·요일·시작/종료 시각으로 바꿔 말한다. 1학기는3/1~6/20, 2학기는9/1~12/21(시작일 포함112일) 서버 기본값을 사용한다. 연도 생략은 한국 시간 현재 연도이며, 직접 지정한 날짜가 우선한다. 계절학기 등 다른 학기는 기간을 질문한다. 수업 시각은 추정하지 않는다. 장소는 선택 사항이다. 여러 과목을 한 번에 최대10개, 과목별 수업시간 최대20개까지 처리한다. 과목별 날짜 범위 안의 해당 요일 수업이 브리핑에 표시된다. 학교 실제 공휴일/휴강/보강은 반영하지 않는다.

`register_courses` apply/answer/cancel 도구. JSON 부분 초안은 conversation_sessions.state.planner.course_pending에 저장된다. answer.values는 현재 질문 중인 과목을 채우며 meetings는 해당 과목의 전체 시간 목록을 교체한다. 모델은 이미 알려진 시간 목록을 보존해야 한다. 번호별 회차 일부 수정/삭제는 지원하지 않는다. 별도 일정 등록이 대기 중이면 먼저 답하거나 취소하도록 한다.

누락 정보가 있으면 일괄 등록 전체를 보류하고, 모든 값이 유효해지면 과목·수업시간·대화 응답·초안 해제를 하나의 기존 세션 트랜잭션으로 저장한다. 같은 요청 ID 재전송은 캐시를 반환한다. 동일 과목명/학기/기간이 존재하면 과목마다 중복 확인을 받는다. 동일 요일/시작 시각 중복은 거부한다. 명시적으로 저장하지 말라는 요청은 도구를 호출하지 않는다.

서버가 실제 저장한 과목명·학기·기간·요일·시간·장소로 영수증을 만들며, 추가 AI 설명 호출은 없다(새 세션의 제목 생성은 별도). 뇌 분석 화면으로 전환하지 않는다. 실제 수업은 구현/시험 과정에서 등록하지 않는다.
